# Label Propagation Algorithm: CUDA parellelization with Julia

A Julia-based CUDA implementation for parallelizing Label Propagation algorithm. Originally developed in Google Colab(.ipynb file), this repository refactors the code into a modular structure for better performance analysis and reproducibility as part of the Parallel and Distributed Systems (Project 3) course. 
The program is built to run on the GPUs of Aristotelis Cluster(with Slurm scripts) and its code is compatible with 'Ampere' architecture specifications (Nvidia A100 GPUs, 'ampere' partition).
